# Perfecto's — Loja responsiva

Landing page responsiva de uma loja fictícia de jaquetas de couro e botas. Projeto de estudo feito com HTML, CSS e JavaScript puro.

## Funcionalidades

- Layout responsivo com menu "hambúrguer" no celular (abre e fecha, e fecha ao escolher um link)
- Dois carrosséis feitos do zero em JavaScript (imagens e depoimentos), com navegação por mouse e teclado
- Depoimentos que trocam sozinhos (desligado para quem ativou "reduzir movimento" no sistema)
- Galeria da coleção em grade
- Imagens otimizadas em WebP e carregamento sob demanda (`loading="lazy"`)

## Rodando

Abra `Projeto-Perfecto's/index.html` no navegador, ou use a extensão Live Server do VS Code.

## Estrutura

```
Projeto-Perfecto's/
├── index.html
├── style/   normalize.css + main.css
├── js/      menu.js, carousel.js, main.js
└── img/
```
